```
数主谓宾法: 数一句话中有几个 主谓/主谓宾 结构
三种情况
- 主干结构 每句话至少有1个主语和1个谓语动词
- 从句 which/that/where
- 并列句 and,or,but

注意点
- 主谓单复需一致 (主单谓单 主复谓复)
- 主动被动要区分 (被动 be done 结构牢记)
- 完成时态常考到 have/has done
- 连词结构需一致 (词连词 短语连短语 形式一致)
- 句子时态要一致

```

## 28 Grammar Rules

名词篇

```
#1 (无冠词) 形容词+可数名词复数结构 (通常考察名词复数形式)
#2 n of n 结构 (名词所有格)
#3 N's n 结构 (名词所有格 表示...的 通常考察后面的名词)
#4 adv+adj+n 结构 (挖孔处可能会在形容词或名词的地方)
#5 because of + n/名词短语结构 (挖空处通常考察名词/名词短语)
#6 there be + n 句型 (通常考察名词 注意根据 be 的单复数形式选择名词的单复数形式)
```

动词篇

```
#7 Be + ved + prep 结构 (包括be的常见变形形式 is are were was 等)
   is _influenced_ by
#8 have/has/had + ved(过去分词) + n
#9 has/have/had been + ved
#10 as/have/had sth ved (挖空处可能在 has 或 ved)
#11 can/should/must/will/cound/might/may/have to + do
#12 句子+that/which 句子结构，that/which如果跟在名词后 且挖空处跟在that/which后，则往往考察/选择动词
#13 主谓单复数保持一致
```

形容词/副词

```
#14 a/an + adj + 可数名词单数 通常考察形容词
#15 be+adj+prep 往往形成固定搭配 考察形容词
#16 stay/remain/grow/become+adj 结构 形成/维持某种状态
#17 it is/was+(so) adj+that 填形容词
#18 n(s)+be+adj 填形容词
#19 more/most+adj 填形容词
#20 adv+ adj/adv 副词修饰副词或形容词 填前面这个 副词
#21 adv+ V 修饰动词
#22 句子成分完整，中间插入逗号并挖空，一般填副词/连接副词，however therefore等
```

介词/连词

```
#23 and/or 的并列用法：用来连接相同类型的成分，如名词、动词、形容词，通常要求并列的单词形式保持一致
#24 如果已经有2个完整句子 往往考察连接词
#25 by doing sth
#26 with sth ved动词过去分词
#27 句子成分完整， 名词后挖空，且挖空后有介词，大概率填 ved 做修饰
#28 如果已经有一个完整句子，挖空在逗号后(有时没有逗号)，直接跟名词/名词短语，则挖空处往往填 Ving 形式做修饰
```
