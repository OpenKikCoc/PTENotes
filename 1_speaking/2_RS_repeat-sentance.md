## 2/5/8 法则 (降调收尾)

1. 流利的说出 2-4 个词
2. 琉璃说出 50% 内容 （理解上半句或下半句）
3. 流利说出 80% 内容 理解整句 跳过不熟悉的单词

错误练习法

```
1. 拿到RA就读
2. 读完评分
3. 不高就再读
4. 达标就下一篇

错误是因为，RA除了卡顿，还关注 重弱读/单词发音准确性/连贯词&不蹦词
```

正确练习法

```
1. 拿到一个 RA 后进行 30s准备
2. 初读按照真考要求做大
3. AI 评分
4. 【纠正并积累错误单词的发音，尤其是红色部分】
5. 进行基础练习，同步跟读方式，学习正确的节奏、意群划分和重弱读
   1) 播放原声(慢速版)自己朗读一遍
   2) 同步跟读慢速版 原声盖过自己的声音
   3) 脱离原声 自己正常语速朗读
```
