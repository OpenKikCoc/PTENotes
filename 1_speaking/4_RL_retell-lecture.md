## RL 整体答题原则

1. 答题要言之有物
2. 不要说和题目内容毫不相关的废话
3. 不要用过度重复的句式

> 答题框架: 开头明确讲座主题，中间呈现至少5-6个来自讲座中的信息句，可以不用收尾。

**开头明确主题**

（主题句一般出现在音频的开头1-2句）

- The talk was about …
- This lecture is about …
- The talk was that …
- The presentation was centered on …

**中间通过过渡词串联内容句**

（将自己笔记中的内容都用下列句式讲完，每句话一定要用不同的句式）

- The speaker first mentioned + 句子
- And then, the speaker has explained that + 句子
- Followed by that, in the lecture, they mentioned + 句子
- From the lecture, we know that + 句子
- So basically, according to the lecture, + 句子
- In addition/what's more, + 句子
- In the end, the speaker said + 句子

**RL答题示范**

```text
The talk was about air pollution.

The speaker first mentioned changes in air pollution.

And then, the speaker has explained air pollution is visible with smogs.

Followed by that, in the lecture, they mentioned smog in London caused death.

In the end, the speaker said that the source of pollution is cars and lorries.
```

**SWT 中的逻辑关系&连接词**

因果关系

| 连接词  | 示例                                                         | 注意事项                                                     |
| ------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| because | I liked swimming and hiking **because** they were fun.           | 通常情况下 because 前面不要加逗号                            |
| since   | **Since** Hubert is not very smart, he never experiences any fear. |                                                              |
| so      | My computer crashed, **so** I lost all my work.                  | 不能把 so 替换成 therefore 或 thus。so 是连接词，therefore 和 thus 都是副词。 |

转折关系

| 连接词          | 示例                                                         | 注意事项                                               |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| but             | Mary is very popular among her classmates, **but** her poor exam scores make her teachers worried. | 不能把 but 替换成 however，因为 however 并不是连接词。 |
| although/though | **Although** / **Though** Mary is very popular among her classmates, her poor exam scores make her teachers worried. |                                                        |

并列关系

| 连接词 | 示例                                                         | 注意事项                                                     |
| ------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| and    | Mary is very good at sports, **and** her classmates are very proud of her. | And 作为两个分句的连接词时，前面需要加逗号                   |
| 分号   | Mary is very good at sports **;** her classmates are very proud of her. | 分号可以连接并列且同级的分句，或者连接两个语义联系紧密的分句 |

目的性关系

| 连接词      | 示例                                                       | 注意事项 |
| ----------- | ---------------------------------------------------------- | -------- |
| in order to | I've studied very hard **in order to** score high in my exams. |          |

描述性关系（时间、地点、作用的等等）

| 连接词 | 示例                                                         | 注意事项 |
| ------ | ------------------------------------------------------------ | -------- |
| when   | **When** it started to rain, we went inside.                     |          |
| while  | **While** Peter is spending a good time on television, Mary is practicing her piano. |          |
| where  | In 1963 we moved to Boston, **where** my grandparents lived.     |          |
| which  | Mindfulness **which** is achieved by meditation techniques is very beneficial. |          |
| that   | The research result **that** has surprised many is undergoing further investigation. |          |
| 双逗号 | Huber **,** a young man who never fears, is not very smart.       |          |

举例

| 连接词  | 示例                                                         | 注意事项 |
| ------- | ------------------------------------------------------------ | -------- |
| such as | This job requires various skills **such as** public speaking, coding and driving. |          |
